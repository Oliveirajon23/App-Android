# Primeiro App Android - Evolução (Tela de Login)

Este repositório contém a evolução da aplicação Android desenvolvida em sala de aula, escrita em **Kotlin** com layouts em **XML**.

## Funcionalidades Implementadas
- Campo de texto para inserção de **E-mail**.
- Campo de texto para inserção de **Senha**.
- Botão de ação que captura os dados digitados nos dois campos e os exibe na tela através de um Toast.

## Como Executar o Projeto

### Pré-requisitos
- **Android Studio** instalado (com Android SDK configurado).
- Dispositivo Android físico (com Depuração USB ativada) ou um Emulador Android (AVD) configurado.
